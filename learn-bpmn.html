CHAPTER 01

BPMNとは？ — 業務の「共通言語」

BPMN（Business Process Model and Notation）は、業務の流れを誰が見ても同じように理解できる図で表現するための国際標準の記法です。

文字だけのマニュアルより、図で表現した方が「誰が・何を・どの順で」行うかが一目で伝わります。BPMNはそのための世界共通のルールです。

「横長の枠＝担当者」「角丸四角＝作業」「矢印＝順序」「丸＝開始/終了」。この4つを覚えれば、もうBPMN図が読めるようになります！

なぜBPMNなのか？

  • 見える化 — 複雑な業務を一目で把握
  • 属人化の解消 — 誰でも同じ手順で業務を遂行できる
  • 改善の発見 — ムダ・重複・ボトルネックが浮き彫りに
  • 研修・引継ぎの効率化 — 図を見せるだけで説明完了
CHAPTER 02

BPMNの基本図形 — たった6種類を覚えよう

BPMNには多くの図形がありますが、実務の9割は以下の6種類で表現できます。まずはこれだけ覚えましょう。

図形名称意味
開始イベントStart Event プロセスの開始点。細い線の円。「申請受付」「月初処理開始」など。
終了イベントEnd Event プロセスの終了点。太い線の円。「処理完了」「通知送信済」など。
タスクTask 個別の作業。角丸の四角形。「申請書を確認する」「データを入力する」など。
排他ゲートウェイExclusive Gateway 条件分岐。ひし形に×。「OKなら次へ、NGなら差戻し」など。
並行ゲートウェイParallel Gateway 同時進行。ひし形に＋。「承認と予算確認を同時に進める」など。
シーケンスフローSequence Flow 実行順序。実線の矢印。タスクとタスクをつなぐ。
この6つを組み合わせるだけで、ほとんどの業務フローが描けます。まずはこの基本セットで練習しましょう。

CHAPTER 05

一目で伝わる図を描く7つのコツ

  1. 左から右へ業務が流れる
    人間の目は左→右に流れるのが自然です。上下にジグザグする図は読む人を疲れさせます。
  2. タスク名は「〜を〜する」で統一
    「申請書を確認する」「データを登録する」のように、目的語＋動詞で書くと誰が見ても意味が明確です。
  3. 1つの図は1ページに収める
    長くなりすぎたらサブプロセス（＋マーク付きタスク）で折りたたみましょう。全体像が把握しやすくなります。
  4. レーン（担当者）を必ず書く
    「誰がやるか」が書かれていない図は、業務マニュアルとして機能しません。
  5. ゲートウェイには必ず条件を書く
    分岐の矢印に「OK」「NG」「5万円以上」「5万円未満」など条件を明記しましょう。
  6. 開始と終了を明確に
    開始イベント（細い丸）と終了イベント（太い丸）を必ず配置します。これがないと「どこからどこまで？」と混乱します。
  7. シンプルに、必要最小限の図形で
    最初から全図形を使おうとしないこと。基本の6種類（第2章）だけで十分なケースがほとんどです。

🎯 セルフチェックリスト

  • フローは左から右に流れているか
  • すべてのタスクに具体的な名前が付いているか
  • 各レーンに担当者が明記されているか
  • 分岐したゲートウェイは適切に合流しているか
  • 開始イベントと終了イベントがあるか
  • 図が1ページに収まっているか
CHAPTER 06

理解度チェック — クイズで確認しよう

ここまで学んだ内容を、3問のクイズで確認しましょう。選択肢をクリックすると正誤が表示されます。

あなたの正解数： 0 / 3
Q1. BPMNで「太い線の円」が表すものはどれ？
A開始イベント
B終了イベント
Cタスク
Dゲートウェイ
正解：B（終了イベント）
細い線の円＝開始イベント、太い線の円＝終了イベントです。線の太さで見分けましょう。
Q2. 「承認」と「予算確認」を同時に進め、両方完了してから次に進みたい。どのゲートウェイを使う？
A排他ゲートウェイ（×）
B並行ゲートウェイ（＋）
C包含ゲートウェイ（○）
Dゲートウェイは不要
正解：B（並行ゲートウェイ）
並行ゲートウェイ（＋マーク）は複数の経路を同時に実行し、すべての完了を待って合流します。排他ゲートウェイ（×）は1つだけ選択する場合に使います。
Q3. 良いBPMN図のルールとして正しくないものはどれ？
Aフローは左から右に統一する
Bタスク名は「〜を〜する」形式で書く
Cレーン（担当者）は省略してよい
D1つの図は1ページに収める
正解：C（レーンは省略してよい）
レーン（担当者）の省略はNGです。「誰がやるか」が書かれていない図は業務マニュアルとして機能しません。必ずレーンで担当者を明示しましょう。
全問正解できましたか？ 間違えた問題は、該当する章に戻って復習してみてください。BPMNは「描いて覚える」のが一番の近道です。
BPMNには絶対の正解はありません。一緒に働く仲間と認識にズレがなければ、それが正解とも言えます。
